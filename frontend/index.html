Как считается оценка

Что оценивается

Для выбранной точки система считает набор простых показателей: расстояния до ближайших объектов, количество объектов в радиусе, площади пересечения с зелеными и водными зонами, а также районные экономические показатели.

Как получается балл

Каждый простой показатель нормируется в шкалу от 0 до 100 по эталонному и браковочному значениям. Затем показатели сворачиваются по дереву: показатель -> подгруппа -> секция -> группа -> итоговая оценка.

Как работают веса

Вес показывает важность элемента среди соседних элементов того же уровня. Сумма весов внутри каждой группы соседей должна быть 100%. Пользовательские веса меняют вклад элементов в итог, но не меняют сами исходные значения показателей.

Оценка и вклад

  • Оценка показывает качество элемента само по себе.
  • Вклад показывает, сколько этот элемент добавляет к уровню выше с учетом веса.
  • Цвет строки строится по оценке, а не по вкладу.

Если нет данных

Если по отдельному показателю нет данных, он не участвует в агрегации для соответствующего уровня. Остальные доступные показатели продолжают участвовать в расчете.
